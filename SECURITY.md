# Security

This repository is documentation plus a paper laboratory Compose tree.

## Reporting a vulnerability

Use **GitHub private vulnerability reporting** for this repository:

https://github.com/Kolzodev712/trading-system-showcase/security/advisories/new

Do not publish interview credentials, JWT secrets, or staged build artifacts from `lab/artifacts/` in public issues.

For vulnerabilities in a component (runtime, simulator, UI), prefer the Security Advisory form on that component repository when the issue is clearly scoped there.

Maintainers triage reports as capacity allows; there is no guaranteed response SLA.
