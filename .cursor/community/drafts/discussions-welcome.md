Welcome.

This organization publishes an open-source **Paper trading laboratory**:

| Repository | Owns |
|------------|------|
| [trading-system-showcase](https://github.com/Kolzodev712/trading-system-showcase) | Ecosystem docs, Compose lab, discussions hub |
| [trading_system](https://github.com/Kolzodev712/trading_system) | Runtime, risk, research |
| [k-paper](https://github.com/Kolzodev712/k-paper) | Standalone paper exchange |
| [trading-system-ui](https://github.com/Kolzodev712/trading-system-ui) | Operator console |

### Get started

1. Clone the four public repos as siblings.
2. Follow https://github.com/Kolzodev712/trading-system-showcase/tree/main/lab (`make doctor && make build && make demo`).
3. Or use k-paper alone: https://github.com/Kolzodev712/k-paper

### Propose improvements / report bugs

- Use **Issues** on the owning component repo (templates provided).
- Security: each repo’s `SECURITY.md` — do not post vulnerabilities publicly.

### Contribute

See each `CONTRIBUTING.md` and the ecosystem [ROADMAP](https://github.com/Kolzodev712/trading-system-showcase/blob/main/ROADMAP.md). Prefer small PRs with local verification (no GitHub Actions).

### Boundaries

Not production/mainnet ready. Research candidates are not validated alpha. Paper lab only for the integrated stack.
